# Rocha Representações

Site institucional — versão 009 (11/10/2026).

## Arquivos da versão 009

O pacote local `Rocha_Representacoes_Abreu_Hospedagem_009.zip` contém `index.html`, `materiais.html`, `styles.css`, `app.js`, `catalog-data.js`, `assets/` (imagens e logomarca) e `catalogos/` (PDF e catálogo de vidros).

## Como publicar

1. Extraia o ZIP e envie os arquivos e pastas extraídos para a **raiz** deste repositório. Não envie apenas o ZIP.
2. Confira se `index.html` está na raiz.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, branch **main** e diretório **/(root)**.

**Status:** o envio dos arquivos do site e a ativação do GitHub Pages ainda estão pendentes. Este README registra apenas as instruções de implantação.
